### Nex-N1：基于统一生态训练、面向大规模环境构建的智能体模型

> 大语言模型向自主智能体演进，亟需从静态模仿转向激励驱动决策，但现有可扩展交互环境基础设施存在短板。本文打造 Nex 生态，:mdnice-bold-italic[从复杂度、多样性、仿真真实性三大维度构建交互场景，并训练出 Nex-N1 模型。该模型实测表现优于主流开源模型，比肩顶尖闭源模型，相关资源已开源。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/02.webp)

::: image-caption
NexA4A 智能体框架工作流：展示从框架描述到生成高质量执行轨迹的完整架构。 NexA4A 实现了自然语言到多智能体架构的自动化转化，重构了智能体训练环境的搭建流程。从计算机体系结构视角，该工作流将人工编码搭建环境转变为模型驱动的自动合成模式，大幅削减大规模环境部署的工程成本。整个流水线拆解为框架解析、配置生成、环境实例化、轨迹输出等独立阶段，可分布式部署在 GPU 集群并行运算。模块化的信息融合、查询合成单元完成任务解耦，既能批量生成异构智能体拓扑结构，扩充训练样本多样性，也有效提升了整体算力资源的综合利用率。
:::

Nex-N1: Agentic Models Trained via a Unified Ecosystem for Large-Scale Environment Construction[7]

### 专家即服务(Expert-as-a-Service)：面向高效、可扩展且稳定可靠的大规模混合专家模型部署

> 混合专家（MoE）模型的动态稀疏调用特性，易导致传统部署系统运行不稳。本文提出 EaaS 部署系统，:mdnice-bold-italic[将 MoE 模块拆分为独立无状态服务，并搭配高性能点对点通信库。实验证明，该系统容错能力优异，硬件故障下吞吐量降幅低于 2%，还能节省 37.5% 算力，适用于大规模 MoE 线上部署。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/03.webp)

::: image-caption
EaaS 整体方案概览。传统专家并行方案需要与其他集合式并行方案共用通信组；EaaS 将混合专家（MoE）层与其他稠密计算组件解耦，实现注意力层与 MoE 层灵活、可扩展的部署。该方案将 MoE 中的专家模块剥离为独立服务：注意力客户端完成计算后，路由模块通过异步点对点连接将词元发送至对应专家服务端，取回计算结果后结合路由权重完成加权求和。(a) 传统标准专家并行架构；(b) 解耦式 EaaS 专家服务架构。
:::

Expert-as-a-Service: Towards Efficient, Scalable, and Robust Large-scale MoE Serving[8]

### ReSpec：面向强化学习系统中推测解码的优化研究

> 大语言模型的强化学习训练受生成环节严重制约，传统推测解码无法直接适配该场景，还存在加速衰减、草稿模型滞后、策略劣化等问题。:mdnice-bold-italic[本文提出 ReSpec 系统，依托三类优化机制完成适配。在通义千问模型上，它最高可实现 4.5 倍加速，同时保证训练收敛性与稳定性。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/04.webp)

::: image-caption
推测解码应用于强化学习训练的整体流程及本文提出的 ReSpec 系统架构。(a) 融合推测解码的标准强化学习训练流程，标注出三大核心问题；(b) ReSpec 系统设计，通过三种互补机制解决上述问题：根据负载动态调整推测解码配置、利用在线策略信号持续对齐草稿模型、依据轨迹质量对草稿模型更新做加权处理。三者协同保障强化学习训练全程高效且稳定。
:::

ReSpec: Towards Optimizing Speculative Decoding in Reinforcement Learning Systems[9]

### TensorIR：面向自动化张量程序优化的抽象层

> 深度学习模型跨设备部署需求日益迫切，各类专用硬件带来丰富的张量计算加速原语，也带来诸多工程难题。:mdnice-bold-italic[本文提出 TensorIR 编译器抽象，革新传统循环嵌套表达，将张量计算作为核心。该工具可自动适配硬件加速原语，跨平台运行性能媲美业内顶尖的手工优化方案。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/05.webp)

::: image-caption
传统编译器分为两大流派：TVM、Halide 等采用自底向上方式，仅对标量循环做变换；Stripe、Fireiron 等采用自顶向下逐层拆解计算，二者都未将张量计算作为核心对象。TensorIR 创新性引入Block抽象，借鉴人工优化的分治思想，把程序解耦为外层循环嵌套与内层张量计算两大模块。Block 携带完整依赖签名作为标准化接口，让内外区域可独立开展循环分块、指令映射等优化，正式将张量计算提升为程序一等公民。该设计融合两类传统方案优势，也是后续自动张量化、调度变换、正确性校验的底层根基。
:::

TensorIR: An Abstraction for Automatic Tensorized Program Optimization[10]

### 在新兴平台高效部署新兴模型：一种自顶向下的测试与调试方案

> 传统机器学习框架难以支撑大模型在浏览器、移动端等新兴平台部署，自下而上的开发模式还存在调试繁琐、效率不足的问题。:mdnice-bold-italic[本文提出 TapML 自上而下部署方案，可自动生成测试数据并渐进迁移模型。该方案已应用于 MLC-LLM，高效完成多款模型跨平台部署，有效提升开发效率。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/06.webp)

::: image-caption
这张图直观对比了传统模型部署流程与 TapML 全新开发范式，集中展现了论文两大核心创新方法论。传统自下而上模式先逐个实现算子、手动编写测试用例，最后再开展全模型验证，一旦整体运行出现精度异常或逻辑错误，无法快速定位故障算子，复合错误排查成本极高。而 TapML 采用自上而下思路，首创算子测试提取与跨平台渐进迁移两大技术：先在成熟平台自动采集真实业务数据生成测试用例，再以混合计算图形式逐个将算子迁移至目标平台，每完成一个算子就同步做单元与全模型校验，把错误范围严格限定在最新迁移模块。该范式从软件开发流程层面解决了新兴平台部署测试难、调试难的行业痛点，是全文最核心的创新体现。
:::

Productively Deploying Emerging Models on Emerging Platforms: A Top-Down Approach for Testing and Debugging[11]

### Relax：面向端到端动态机器学习的可组合抽象机制

> 动态形状计算在大语言模型等机器学习任务中尤为关键，模型跨多终端部署的需求不断提升。:mdnice-bold-italic[本文提出 Relax 编译器抽象，整合多层计算表达，依托符号形状标注实现动态形状全局优化。实验证明，该框架性能对标业内主流方案，可支持模型在手机、嵌入式设备、浏览器等多类环境部署。]

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/07.webp)

::: image-caption
传统机器学习编译器把计算图、张量程序、外部库划分为独立层级，采用单次单向降级策略，无法开展跨层级协同优化。Relax 的跨层级抽象打通层级壁垒，让三类计算单元自由调用协作。一等符号形状注解摒弃简单的未知维度标记，借助符号变量记录维度间数学关联，为算子融合、内存规划等优化提供支撑。该架构专为大语言模型这类动态形状密集型任务设计，是各类跨层级优化落地的基础，可保障动态模型在不同硬件后端的编译与运行效率。
:::

Relax: Composable Abstractions for End-to-End Dynamic Machine Learning[12]

### Apache TVM：开放的机器学习编译器框架

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/08.webp)

::: image-caption
TVM 目标是汇聚多领域从业者，打造易用、灵活、高效的开源框架，为各类硬件平台优化机器学习模型。核心特点：以 Python 为首要开发方式，可快速定制编译流程；支持全场景部署，能将模型编译为轻量化可部署模块；性能优异、适配范围广、设计灵活、上手简便，可运行于数据中心 GPU 到边缘设备等各类硬件。

### MLC LLM：基于机器学习编译的通用大语言模型部署引擎

### PyPTO：面向并行张量/Tile 操作的编程范式

> PyPTO 是面向 AI 加速器的高性能编程框架，采用 PTO 并行张量分块范式，以硬件感知 Tile 数据块为核心。**依托多层中间表示完成编译优化，自动生成设备可执行代码，分层抽象适配算法、性能调优、系统开发三类人群，提供简洁 Python API，内置大模型算子样例，配套完整调试工具链。**

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/10.webp)

::: image-caption
PyPTO 作为 Python 原生 Tile 编程融合算子框架，相较 Triton、TileLang、CuTile等同类工具优势突出。它以 Tile 为核心编程范式，搭配类 PyTorch 的 Python 语法，屏蔽硬件底层细节，大幅降低高性能算子开发门槛。依托 PTO 虚拟指令集，它实现硬件跨代兼容，解决了传统指令集迭代适配难的问题。其独创白盒编译，将编译流程可视化，支持人机协同闭环调优，后续还将接入 AI Agent 智能优化。实测它相比 Ascend C 代码行数大幅缩减，推理性能接近原生，兼顾易用性、兼容性与高性能。
:::

- 项目地址：https://github.com/hw-native-sys/pypto

### Apache TVM FFI：面向机器学习系统的开放 ABI 与 FFI

> Apache TVM FFI[17] 是 Apache 旗下面向机器学习系统的开源 ABI 与 FFI 项目。

它具备稳定精简的 C ABI，依托 DLPack 实现主流框架间零拷贝数据互通，原生支持 Python、C++、Rust 多语言。可实现一次打包适配多框架与 Python 版本，采用 Apache-2.0 开源协议。

![文章插图](/articles/2026-06-10-ai-phd-70bd47e4/images/11.webp)

::: image-caption

:::

## 上海创智学院概况

> 如果你对加入冯老师团队从事 MLSys 研究感兴趣，相信你也会关注上海创智学院的整体培养环境。这所新型 AI 人才培养机构的详细情况如下：

上海创智学院[41]由高校、企业、科研机构联合共建，主打**AI 领军人才培养**，秉持“以学生为中心、以前沿为牵引”理念，从师资、培养、保障三方面搭建育人体系。

1. **顶尖师资** 组建全职、兼职、产业三类导师队伍，实行**导师组培养制** 与 Tutor 帮扶机制；导师评价侧重创新价值，搭建交流平台促进经验共享。
2. **特色培养** 兼顾思政教育，打造动态前沿课程；修读与毕业规则灵活，无强制学制；紧扣国家与产业需求设立科研课题，依托各类学术活动营造多元学术氛围。
3. **全面保障** 坐落于人工智能小镇，拥有 2.7 万平米专属场地；布局专业算力，规划建设万卡规模算力资源；配套完整创业孵化支持，同时配齐办公、运动、食宿等生活设施，学生均享单人宿舍。
