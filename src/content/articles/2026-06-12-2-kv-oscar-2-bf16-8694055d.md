## 一、问题本质与动机分析

### 1.1 KV 缓存量化的核心困境

> **长上下文推理时代，KV 缓存已成为大模型服务的主要成本来源**。在自回归解码过程中，缓存随上下文长度、批次大小和模型深度线性增长，每个新 token 都需要从 GPU 内存中读取缓存的大部分内容。

**KV 缓存压缩因此成为增加批次大小和减少内存流量的直接途径**。在众多设计选择中，:mdnice-bold-italic[INT2 量化尤其具有吸引力：它承诺大幅减少内存使用，同时保留硬件友好的固定宽度表示。]

::: block-1
然而，**将 KV 缓存激进压缩到超低精度（如 INT2）仍然极具挑战性。KV 激活中包含严重的通道级离群值**：一小部分通道通常表现出极大的幅值，而大多数通道保持相对良好的行为。**在低比特量化下，这些离群值主导了量化尺度**，:mdnice-bold-italic[将大多数正常值压缩到只有少数有效量化级别，从而大幅降低注意力质量。]
:::

### 1.2 旋转基量化的局限

> 基于旋转的量化通过应用固定的正交变换（如 Hadamard 旋转）来解决这个问题，该变换将少数极端激活值重新分布到多个通道，产生更均匀的激活分布以便于量化。此外，旋转保留张量维度并应用固定的线性变换，不引入每通道路由或不规则的稀疏元数据。

这使得它与分页 KV 缓存布局和 FlashAttention 风格的融合解码内核天然兼容：每个 KV 向量在量化前简单地移动到条件更好的基中，在分页注意力使用时再移回。

但是，随机旋转仍然是数据盲目的。**它可以平滑激活范围，但不知道哪些方向对注意力重要**。在 INT2 精度下，这种区别至关重要：只有四个量化级别可用，因此误差应该被推入模型读取强度较低的方向。

### 1.3 注意力感知的必要性

> 注意力操作在键和值诱导的相关性和分数加权交互上运行，而不是在它们的原始欧几里得表示上。**这表明最优旋转目标应该从注意力统计本身导出。**

![文章插图](/articles/2026-06-12-2-kv-oscar-2-bf16-8694055d/images/05.webp)

::: image-caption
图 1：OSCAR 整体流程概览。离线阶段，OSCAR 计算注意力感知的键 / 值协方差旋转矩阵，该变换可让 KV 激活值分布更均匀：哈达玛变换抹平激活值极值，而 OSCAR 旋转则区分出对注意力重要与非重要的特征方向。在线推理阶段，分页式 SGLang 缓存中，锚点 token 和最新 token 保留 BF16 精度，历史 KV token 则执行固定的旋转 - 截断 - INT2 量化流程。右侧图表总结：OSCAR 在多模型上维持精度，吞吐量接近 QuaRot (INT2)，且远超 BF16 基线。

图 1 左侧直观地展示了这一点：虽然数据盲目的旋转可以部分平滑离群值，但它们对于 INT2 量化仍然不足。相比之下，**协方差感知的旋转产生了实质上更平滑的激活分布，从而实现有效的量化。**

对于键 K，下游 logit 失真为：

$\left| Q K^{\top}-Q \hat{K}^{\top}\right| _{F}^{2}=tr\left((K-\hat{K}) Q^{\top} Q(K-\hat{K})^{\top}\right)$

它由查询协方差 $Q^{\top} Q$ 控制，而不是单独由 $K^{\top} K$ 控制。

对于值 V，量化后的 $\widehat{V}=Q(V)$，下游输出失真为：

$| S V-S \hat{V}| _{F}^{2}=tr\left((V-\hat{V})^{\top} S^{\top} S(V-\hat{V})\right)$

它取决于注意力分数如何加权值行。

因此，如果目标是减少经验注意力失真而不是原始缓存重建误差，旋转应该从注意力计算本身诱导的目标协方差中估计。

> 图 2 说明了这种差距。朴素 INT2、仅 Hadamard 旋转和仅裁剪仍然留下大量的注意力分数发散和输出误差。相比之下，OSCAR 在量化前使用注意力感知的校准目标协方差，在四个子图中都减少了误差。

**旋转的目标选择比是否旋转更重要**。选择正确的协方差矩阵进行对角化，是 2 比特量化成功的决定性因素。
:::

## 二、OSCAR 算法设计详解

### 2.1 两阶段架构设计

> OSCAR 方法包含两个阶段：离线阶段估计协方差、构建逐层旋转矩阵并拟合每个 token 的裁剪阈值；在线阶段在服务期间基于混合精度缓存布局应用结果的固定变换。

所有协方差和旋转都从一个小的校准数据集离线估计。对于每一层和注意力头，我们从校准激活中构建注意力感知的目标协方差来确定基础旋转。

### 2.2 查询感知的键目标协方差

对于查询行 q，引入注意力感知的键目标协方差 $Q^{\top} Q$，其实证估计量为：

$C_{Q}=\frac{1}{N} \sum_{n=1}^{N} q_{n}^{\top} q_{n}$

应用特征分解：

$C_{Q}=U_{Q} \Lambda_{Q} U_{Q}^{\top}$

并定义旋转为 $R_{k}:=U_{Q}$。

这里的核心思想是：:mdnice-bold-italic[我们不按照键自身的方差分布来旋转，而是按照查询如何 "看待" 键的方式来旋转。那些在查询空间中方差大的方向，就是注意力计算中真正重要的方向，应该在量化中获得更多保护。]

### 2.3 分数感知的值目标协方差

对于注意力矩阵 $S=softmax_{row }(Q K^{\top} / \sqrt{d})$，我们启发式地定义目标协方差：

$C_{S}=\frac{1}{N} V^{\top} S^{\top} S V$

然后计算特征分解：

$C_{S}=U_{S} \Lambda_{S} U_{S}^{\top}$

并定义原始旋转为 $R_{v}:=U_{S}$。

::: block-1
值的旋转目标更加微妙：**值最终是通过注意力分数加权聚合的，因此那些被高注意力分数频繁读取的值方向，才是真正重要的**。通过 $S^{\top} S$ 加权，我们本质上是在计算值在注意力输出中的有效贡献协方差。
:::

### 2.4 复合旋转构造

> 遵循基于旋转的低比特量化方法，我们将基础旋转与 Hadamard 变换 $H_{Had}$ 和位反转排列 $P_{br}$ 组合，形成键和值的最终旋转：

$R_{K}=U_{Q} H_{Had} P_{br}, R_{V}=U_{S} H_{Had} P_{br}$

这里 $R_k$ 和 $R_v$ 是协方差基础旋转，而 $H_{Had}$ 通过重新分布通道能量进一步改善量化几何，$P_{br}$ 交织大方差和小方差通道，使得相邻通道具有相似的动态范围。

这种三层复合旋转设计体现了工程上的精妙平衡：

- 特征基旋转 $U_Q/U_S$ 确保重要方向被识别和保护
- Hadamard 变换确保能量均匀分布
- 位反转排列确保量化分组内的动态范围一致

### 2.5 尺度确定与逐 token 裁剪

量化后端遵循标准的训练后量化实践。我们对键和值都使用带尺度和零点的仿射非对称 INT2 量化，结合基于百分位的裁剪来控制离群值。

裁剪阈值从旋转后的校准激活逐层估计，而不是在下游任务上调优。**实验表明，校准导出的点 $(c_K, c_V)=(0.96, 0.92)$ 接近最佳网格点，证实 OSCAR 的裁剪阈值不需要手动调优。**

### 2.6 环境误差假设下的最优性

> 定理 1（环境基对角残差下简单谱变体的最优性）：考虑键和值基础旋转的冻结误差代理目标：

$\tilde{L}_{K}(R_{k})=tr(R_{k}^{\top} C_{Q} R_{k} E_{K}), R_{k}^{\top} R_{k}=I_{d}$

$\tilde{L}_{V}(R_{v})=tr(R_{v}^{\top} C_{S} R_{v} E_{V}), R_{v}^{\top} R_{v}=I_{d}$

假设冻结（独立于输入和旋转）的残差协方差在环境基中是对角的：

$E_{K}=\sum_{j=1}^{N}\left(\mathcal{Q}\left(k_{j} R_{k}\right)-k_{j} R_{k}\right)^{\top}\left(\mathcal{Q}\left(k_{j} R_{k}\right)-k_{j} R_{k}\right)=diag\left(\mu_{1}, ..., \mu_{d}\right), \mu_{1} \leq \cdots \leq \mu_{d}$

$E_{V}=\sum_{j=1}^{N}\left(\mathcal{Q}\left(v_{j} R_{v}\right)-v_{j} R_{v}\right)^{\top}\left(\mathcal{Q}\left(v_{j} R_{v}\right)-v_{j} R_{v}\right)=diag\left(\eta_{1}, ..., \eta_{d}\right), \eta_{1} \leq \cdots \leq \eta_{d}$

那么，在校准数据集上：$R_{k}=U_{Q}$ 和 $R_{v}=U_{S}$ 是 $\tilde{L}_{K}(R_{k})$ 和 $\tilde{L}_{V}(R_{v})$ 的最小化器。

**这个定理从理论上证明了为什么注意力感知的协方差目标是最优的**：在冻结残差协方差在环境基中为对角的合理假设下，:mdnice-bold-italic[将大方差的重要方向与小量化误差对齐，将小方差的不重要方向与大量化误差对齐，可以最小化整体的加权误差。]

::: block-1
OSCAR 的旋转本质上是一种 "误差路由" 机制：它主动将量化误差推送到注意力计算中最不重要的方向，从而在相同比特预算下实现最小的最终精度损失。
:::

## 三、系统设计：2 比特 KV 缓存的在线服务

### 3.1 KV 缓存布局

> OSCAR 作为 INT2 KV 缓存模式集成到 SGLang 服务栈中，与分页注意力完全兼容。该实现保留了两个短的高精度窗口：前 $S_0$ 个 token 作为注意力 sink，以及当前位置之前最近的 W 个 token。中间上下文的其余部分在固定的 OSCAR 旋转后以 INT2 存储。

因此，在解码位置 t，逻辑缓存由以下部分组成：

$\underbrace {[1,S_{0}]}_{bf16 sink}| \underbrace {[S_{0}+1,t-W]}_{int2 history }| \underbrace {[t-W+1,t]}_{bf16 recent}$

这种混合精度布局是经过精心设计的：

- 注意力 sink 现象：前几个 token 始终被所有位置高度关注，必须保持高精度
- 最近窗口效应：最近的 token 通常对当前生成最重要，也需要高精度保护
- 历史主体：大量中间历史 token 可以安全地量化为 INT2

::: block-1
消融研究表明**，$(S, R)=(64, 256)$ 是一个明显的甜点：更小的窗口会留下明显的精度损失，而更大的窗口以实质上更多的 BF16 KV 内存为代价提供可忽略的额外精度**。在 128K 上下文长度下，这仅占用 0.24% 的额外 BF16 KV 内存。
:::

### 3.2 KV 缓存更新机制

> 在预填充期间，运行时通过完全融合的 Triton 内核写入缓存行。对于具有 BF16 行 $k_t$，$v_t$ 和裁剪值 $\tau_t^{(K)}$，$\tau_t^{(V)}$ 的 token，存储的 INT2 为：

$k_{t}^{+}=\mathcal {Q}_{2}^{+}(clip(k_{t}R_{K},\tau _{t}^{(K)})), v_{t}^{+}=\mathcal {Q}_{2}^{+}(clip(v_{t}R_{V},\tau _{t}^{(V)}))$

每字节打包四个 2 比特值。

新的解码 token 将首先作为 $k_t R_K$ 和 $v_t R_V$ 写入最近窗口。随着解码推进，最旧的最近 token 将通过融合的 Triton 内核降级到 INT2 中间区域，该内核应用相同的裁剪 - 量化操作。OSCAR 然后通过将 $R_V$ 吸收到模型的投影权重中来优化值旋转，实现计算节省和延迟减少。

### 3.3 解码注意力内核

> 在解码期间，OSCAR 在 GPU 上将每个请求的缓存索引划分为 BF16（sink + 最近）和 INT2 段。INT2 内核解包字节，应用存储的尺度 / 零点参数，并在浮点中累积它们。

现有的解码注意力内核通常由两个内核启动组成：一个用于沿序列维度并行处理 KV 缓存段，第二个用于通过在线 softmax 合并来自段的部分注意力结果。:mdnice-bold-italic[OSCAR 为 BF16 KV 缓存注意力引入了一个额外的内核，然后重用第二个合并内核来搭载高精度部分结果的合并。由于 BF16（sink + 最近）段的元素比 INT2 段少几个数量级，开销可以忽略不计。]

### 4.3 消融研究

#### 旋转分解分析

OSCAR 的组合旋转是 $R=U \cdot H_{Had} \cdot P_{br}$，即注意力感知特征基 U、Hadamard 变换 $H_{Had}$ 和位反转排列 $P_{br}$ 的乘积。

> 两个关键发现浮现：

1. 注意力感知特征基 U 和 Hadamard 分量 $H_{Had}$ 都有实质性贡献；位反转排列 $P_{br}$ 在浮点数学中不改变精度，但通过交织大小特征值改善量化几何，使得每分组量化看到更均匀的范围。
2. 没有任何替代旋转目标（随机 Hadamard、原始 $K^{\top} K / V^{\top} V$ 重建目标、随机正交）在相同的 INT2 预算下能匹配注意力感知的 $C_Q / C_{SQ} / C_S$ 目标；分数加权变体协方差 $C_{SQ}$ 比单独的 $C_Q$ 提供进一步改进。

这隔离了论文的核心主张：对角化哪个协方差矩阵比是否对角化更重要。

#### 校准数据机制

**OSCAR 对校准量或域不敏感**。默认的 8k GPQA-Diamond 校准接近最佳设置，支持小型一次性校准通过。这是一个极其重要的工程特性：不需要针对每个任务进行专门校准，一次通用校准即可。

## 五、相关工作

### 5.1 KV 缓存压缩研究方向

> KV 缓存管理已经成为一个活跃的研究领域，主要分为几个研究方向：

- 基于丢弃的方法如 H2O 通过识别和保留重命中 token 来压缩 KV 缓存。这些方法:mdnice-bold-italic[引入了稀疏元数据和不规则的内存访问模式，与现代分页注意力和融合内核的集成变得复杂。]
- 基于通道的方法如 KIVI 和 Kitty 使用通道级精度提升、残差缓冲器或每通道尺度。这些方法:mdnice-bold-italic[需要自定义页面布局或额外的元数据开销]，难以集成到标准服务流水线中。
- 基于量化的方法是最具部署友好性的方向。KVQuant、WKVQuant 等工作探索了 4 比特及以上的 KV 缓存量化，**但 2 比特量化始终存在精度障碍。**

### 5.2 旋转基量化的演进

> 旋转基量化起源于权重量化领域：

- QuaRot、QuIP#、SpinQuant 等工作证明了正交旋转可以平滑激活离群值，实现更激进的权重量化。
- Saw-INT4 首次将旋转思想系统地应用于 KV 缓存量化，证明了 4 比特旋转 KV 缓存可以在实际服务中实现。但 2 比特仍然是一个未突破的壁垒。
- QuaRot-INT2 尝试直接将 Hadamard 旋转应用于 2 比特 KV 缓存，但如表 2 所示，在小模型上基本上完全崩溃。

### 5.3 OSCAR 的比较优势

> OSCAR 相对于现有工作的核心优势在于三个层面：

1. 目标函数的本质差异：所有先前的旋转方法都以最小化原始张量重建误差为目标，而 OSCAR 以最小化最终注意力输出误差为目标。这是范式级的差异，不是简单的工程改进。
2. 键值分离的精细处理：OSCAR 为键和值设计了不同的旋转目标，认识到它们在注意力计算中扮演的不同角色。先前的方法通常对键和值应用相同的旋转。
3. 系统级的完整解决方案：OSCAR 不仅是算法创新，还提供了完整的生产级服务系统实现，包括混合精度布局、融合 Triton 内核、与分页注意力和前缀缓存的完全兼容。

::: block-1
OSCAR 的真正突破不在于它找到了更好的旋转矩阵，而在于它**重新定义了旋转优化的正确目标函数。**
:::

## 六、结论与展望

### 6.1 结论总结

> OSCAR 提出了一种 INT2 KV 缓存量化方法，从注意力感知的目标协方差而不是原始缓存重建中选择旋转。通过一次离线校准通过，OSCAR 固定键 / 值旋转和裁剪阈值，然后使用融合的 SGLang 路径量化历史 KV token，同时保留 sink 和最近的 token。

**这种简单的目标和内核协同设计恢复了朴素 INT2 丢失的大部分 BF16 精度，同时保持了 2 比特 KV 缓存的内存和服务优势。**

从 4B 到 358B 参数的广泛评估证明：

- OSCAR 在 2.28 比特每元素下保持接近 BF16 的精度
- 在 128K 长上下文检索中保持鲁棒性
- 系统层面实现高达 7 倍的吞吐量提升和 3 倍的单用户解码加速
- 与现代 LLM 服务框架无缝集成

### 6.2 进阶分析

> 要说本方法是否从根本上解决了问题？ **OSCAR 并没有从根本上解决 2 比特量化的信息损失问题，而是通过智能的 "误差路由" 将损失引导到最不重要的方向**。它是在:mdnice-bold-italic[特定假设下的阶段性缓解，而不是终极解决方案。当上下文长度继续增长到百万级别时，累积误差仍然可能成为问题。]

- 方法论的隐含假设和边界条件：OSCAR 的最优性定理依赖于 "冻结的残差协方差在环境基中是对角的" 假设。这个假设在实践中大致成立，但并非严格成立。此外，校准数据需要具有合理的代表性，极端分布外的输入仍然可能遇到问题。
- 隐性成本：OSCAR 需要一次离线校准通过，虽然这个开销很小（仅需 8k token），但对于频繁更新的开源模型生态来说，这仍然是一个额外的部署步骤。此外，旋转操作本身虽然开销很小，但并非零成本。
- **表现欠佳的场景**：从实验数据看，OSCAR 在极小模型（4B 级别）上仍然有 3.78 个百分点的精度差距。:mdnice-bold-italic[这表明小模型对量化噪声更为敏感。此外，在极端长上下文（128K 以上）的检索任务中，OSCAR 的性能也开始明显下降。]

### 6.3 未来工作

> 基于论文的局限性与核心思想，以下是值得探索的后续研究方向：

1. **扩展到权重量化**：注意力感知的协方差旋转思想理论上可以扩展到权重量化领域，可能实现更高质量的 2 比特权重量化。
2. **动态在线校准**：当前 OSCAR 使用固定的离线旋转。探索在线自适应旋转，根据实际输入分布动态调整，可能进一步提高鲁棒性。
3. 更低比特探索：既然 2 比特已经变得可行，1 比特 KV 缓存量化现在成为一个值得探索的新前沿。
4. **与稀疏化的结合**：将协方差感知旋转与 KV 缓存稀疏化技术结合，可能实现更高的压缩率。
5. 训练感知的量化：当前 OSCAR 是训练后量化方法。在训练过程中引入旋转感知的正则化，可能进一步提高量化质量。

::: block-1
OSCAR 打开了 2 比特 KV 缓存实用化的大门，但这仅仅是开始。注意力感知的优化范式将继续重塑我们对低比特量化的理解边界。
