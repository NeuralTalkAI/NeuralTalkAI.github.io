## Core ML

> Core ML 旨在以最有效的方式充分发挥强大的**硬件技术优势**，包括 **CPU、GPU 和神经网络引擎**，以便尽可能地**提高性能**，同时尽量**减少内存占用和功耗**。Core ML 目前针对各种类型模型的设备端性能进行了优化，能够充分利用 Apple 硬件并尽可能地减少内存占用和功耗。

![文章插图](/articles/2021-08-07-core-ml-create-ml-647afc83/images/02.webp)

**https://developer.apple.com/cn/machine-learning/core-ml/**

## Create ML

> 通过 Create ML ，体验**在 Mac 上训练机器学习模型的全新方式**。Create ML **让模型训练变得不再复杂**，同时还能生成强大的 Core ML 模型。
>
> 除了 macOS 外，**iOS 和 iPadOS 上现在也以 Swift 框架的形式提供 Create ML** 的强大功能。使用 Swift 脚本或 Playground，通过编程方式试验并实现模型创建自动化。构建利用 Create ML API 的动态 app 功能，**直接使用用户输入的内容或设备端行为训练模型，在保护用户隐私的同时，为其提供个性化的自适应式体验**。
