关键词：GPU 内核优化、**编译器-Agent 协同设计**、Cake 自进化 IR、**Blackwell 架构**、:mdnice-bold-italic[内核自动化进化]

> 当前 **GPU 内核编程智能体与编程语言领域各自独立演进，二者之间的断层正导致大量专家级内核优化潜力流失**。:mdnice-bold-italic[传统内核智能体将编译器视为固定黑盒，仅能获取编译错误、正确性结果与端到端时延三类反馈]，无法定位同步失败、硬件契约违反或流水线停顿的具体成因；:mdnice-bold-italic[现有编程范式中，高层 Tile 级 DSL 隐藏了 warp 特化、屏障编排与存储层级排布等专家级优化细节，底层 DSL 虽暴露控制力却要求复杂的布局代数推导]，使得智能体的错误既高发又难定位。

> 针对这一困境，NVIDIA 与卡内基梅隆大学联合提出 CAKE 框架，**首次实现编译器与内核智能体的协同设计**。

框架核心为 Cake IR——:mdnice-bold-italic[一种带类型、硬件显式的调度表示层，无需布局代数即可提供细粒度硬件控制]，同时携带充足信息供验证器与成本模型在编译前完成程序推理；配套编译套件返回本地化的正确性与性能诊断，且:mdnice-bold-italic[套件本身也作为进化目标]，将反复出现的失败沉淀为新的验证规则、IR 原语、成本模型校准项与可复用优化策略。

![文章插图](/articles/2026-08-28-cake-ir-kda-2-05-e54c4d68/images/02.webp)

::: image-caption
图 1：Cake 整体架构。图中 (a) 为现有内核 Agent 的经典范式：仅存在内核进化单循环，优化 Agent 生成候选后送入黑盒编译运行环境，仅返回正确性与时延结果，编译器作为固定工具不发生进化，遇到能力边界即陷入停滞。(b) 为 CAKE 的双循环嵌套架构：在内层内核进化循环之外，新增外层编译器 - 运行时进化循环，内核进化产生的所有证据（失败案例、性能数据、调试日志）均反哺编译器，驱动验证规则、IR 原语、成本模型的持续升级，编译器能力提升又反过来提高内层进化效率，形成双向协同的正向飞轮。
:::

实验展现出显著优势：

- 在 B200 显卡的 Flash-KMeans 干净启动实验中，**8000 万 token 预算下，Cake IR 路径最优内核中位数性能达到调优后 FlashML 基线的 1.144 倍**，直接 CUDA/PTX 路径仅为 0.928 倍；Cake 组 3 次实验全部达标，CUDA 组 0 次达标，:mdnice-bold-italic[主动进化耗时中位数仅 1.89 小时，不足 CUDA 路径的一半。]
- 前沿内核合成场景下，**智能体生成的 Kimi Delta Attention 相对官方实现 2.05 倍几何平均加速**，并通过端到端服务验证；:mdnice-bold-italic[Alpha-MoE 融合巨内核端到端 API 级加速最高达 6.204 倍]。已知内核复刻测试中，11 组对比有 10 组达到或超越业界标杆，MQA 索引器性能提升最高达 27%。

目前 CAKE **已覆盖从 Ampere 到 Blackwell 全系列 NVIDIA 架构**，验证语料包含 28 个内核家族、超 400 个用例；基于调度器（Scheduler）的 KNN 与 KMeans *内核族* 在超 400 种形状下实现 1.42×–2.12× 性能提升，**已有 4 项优化合入 FlashInfer 上游代码库。**

*注：内核族（kernel family）是针对同一类核心计算逻辑、面向不同输入形状 / 参数规模 / 硬件场景做了差异化优化的一组 GPU 内核的集合。它们共享算法主干，但各自适配不同的输入尺寸区间，通过统一的分发器（dispatcher）对外提供调用入口，是生产级 GPU 算子库的基本交付单元。*
