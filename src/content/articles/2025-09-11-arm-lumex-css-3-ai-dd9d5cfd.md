## 从集成到优化：Arm Lumex CSS 平台引领设备端 AI 支撑体系升级

> 借助全新 Arm Lumex CSS 平台，加速开发周期并实现可扩展、高性能的设备端 AI。该平台通过紧密集成硬件与软件，有效缩短产品上市时间，同时满足整个生态系统对设备端 AI 体验日益增长的需求。

![文章插图](/articles/2025-09-11-arm-lumex-css-3-ai-dd9d5cfd/images/02.webp)

移动设备正逐步演变为具备 AI 能力的工具，这些工具能够自适应、预判需求，并改善我们与世界的互动方式。然而，随着设备端 AI 变得愈发先进和复杂，移动芯片（手机等移动设备的核心处理器，是实现计算功能的关键硬件）所面临的压力也在不断加大。

产品周期的加速——即每一代全新旗舰移动设备的推出速度都比上一代更快——意味着芯片供应商和原始设备制造商（直接组装生产产品并贴上自有品牌的厂商，如手机品牌厂商）需要在更紧迫的时间范围内实现创新，且容错空间更小。为维持 AI 性能而采用的先进封装技术，在空间和散热受限的移动设备形态（手机、平板等移动设备的物理尺寸和结构）下难以实现。最后，向更先进的制程节点（如 3 纳米）过渡会带来极大的设计复杂度——制程节点指芯片制造过程中晶体管之间的距离，数值越小，芯片集成度越高、性能越强，3 纳米即代表晶体管间距约为 3 纳米。

这正是 Arm 推出集成平台的原因：该平台将 Arm 中央处理器（CPU）——作为计算机的运算和控制核心，相当于设备“大脑”——、图形处理器（GPU）——主要负责图形渲染和并行计算，在游戏、AI 等场景中发挥重要作用——的知识产权（IP，即芯片设计的核心技术方案，属于知识产权范畴），与物理实现方案及可直接部署的软件栈（由一系列相互配合的软件组件构成，可直接用于产品开发）相结合，既能缩短产品上市时间，又能在最新的尖端制程节点上实现一流性能。而 Arm Lumex 是这一平台的下一代演进成果：作为全新打造的专用计算子系统（CSS，Compute Subsystem 的缩写）平台，它旨在满足旗舰移动设备和个人计算机（PC）对设备端 AI 体验日益增长的需求。

## 为 AI 优先时代重新设计

Lumex 将最新的、经过协同设计和协同优化的 Arm 计算 IP（具备先进功能）整合到一个模块化且高度可配置的平台中，具体包括：

::: block-1
- 全新 Armv9.3 C1 CPU 集群：由多个 CPU 核心组成的计算单元，可通过协同工作提升处理能力。其在每周期指令数（IPC）性能上处于领先地位，IPC 是衡量 CPU 每一个时钟周期能执行指令数量的指标，数值越高，CPU 性能越强；同时内置 Arm 可扩展矩阵扩展 2（SME2）单元——SME2 是针对 AI 计算优化的指令集扩展技术，能提升 CPU 处理矩阵运算的能力，而矩阵运算正是 AI 任务的核心运算类型——最终为 CPU 集群带来响应更快、效率更高的 AI 体验。
- 全新 Arm Mali G1-Ultra（GPU 型号）：凭借下一代光线追踪功能——该技术能模拟真实世界的光线传播效果，让游戏画面更具真实感，比如阴影、反射等效果更逼真——提供桌面级视觉效果和更丰富的游戏体验，同时实现更快的 AI 推理。AI 推理指 AI 模型利用已训练好的参数对新数据进行计算并得出结果的过程，是 AI 应用落地的关键环节。
- 全新系统 IP：包括 Arm SI L1 系统互连与 Arm MMU L1 系统内存管理单元。其中，Arm SI L1 系统互连是负责芯片内部不同组件之间数据传输的关键模块；Arm MMU L1 系统内存管理单元则用于管理 CPU 对内存的访问，负责虚拟地址与物理地址的转换，确保内存使用的高效与安全。该系统 IP 旨在消除系统性能瓶颈，同时在推理密集型与计算密集型工作负载中降低延迟——推理密集型工作负载指以 AI 推理任务为主的负载，计算密集型工作负载指需要大量计算资源的负载；延迟即数据从发出请求到得到响应的时间，数值越低，用户体验越流畅。
- 支持 3 纳米制程的 CPU 和 GPU 物理实现方案：专为实现行业领先的 PPA 而打造——PPA 即功耗、性能、面积，是衡量芯片设计优劣的三大核心指标：功耗低意味着设备更省电，性能强代表处理速度更快，面积小则能让芯片体积更小、成本更低——同时为芯片实现旗舰级性能提供更快捷的路径。
:::

## 跨 CPU 与 GPU 技术，提升实际场景中的 AI 性能

在 CPU 方面，支持 SME2 技术的 Armv9.3 C1 CPU 集群，结合 Arm KleidiAI（Arm 推出的 AI 软件工具集）——能为 AI 开发常用的主流框架（如 TensorFlow、PyTorch）与运行时库提供原生支持，其中主流框架可简化 AI 模型的开发和部署，运行时库是程序运行过程中需调用的代码库，提供基础计算功能——在相同条件下，相较于上一代 CPU 集群，在一系列 AI 工作负载中实现了显著的速度提升。这些 AI 工作负载包括传统机器学习推理、语音处理与生成式 AI：传统机器学习（ML）是人工智能的分支，专注于让计算机通过数据学习并改进性能；生成式 AI 是能生成文本、图像、音频等内容的 AI 技术，典型例子如 ChatGPT、AI 绘画工具。此外，该 CPU 集群的 AI 性能提升了 5 倍，效率提升了 3 倍。这些由 SME2 技术带来的改进，意味着用户在使用心仪的消费类设备时，能获得更流畅的 AI 交互体验，且设备续航时间更长。

![文章插图](/articles/2025-09-11-arm-lumex-css-3-ai-dd9d5cfd/images/04.webp)

此外，得益于微架构改进与核心间更紧密的集成，C1 CPU 集群在性能和效率上树立了新标杆——微架构指 CPU 内部的电路设计和组件布局，直接影响 CPU 的性能与功耗，具体优势包括：

- 在相同条件下，相较于上一代 CPU 集群，在六项行业领先的性能基准测试中平均性能提升 30%——性能基准测试是用于衡量硬件性能的标准化测试程序，可直观对比不同产品的性能差异；
- 在相同条件下，相较于上一代 CPU 集群，在主流应用（包括游戏和视频流媒体）中平均速度提升 15%——视频流媒体指通过网络实时传输视频数据的服务，如在线视频播放；
- 在相同条件下，相较于上一代 CPU 集群，在日常移动工作负载（如视频播放、社交媒体使用和网页浏览）中平均功耗降低 12%；
- 与上一代 Arm Cortex-X925 CPU 相比，Arm C1-Ultra CPU 的每周期指令数（IPC）性能实现了两位数（10%以上）的提升。

Mali G1-Ultra 进一步提升了 AI 性能和效率，相较于上一代 Arm Immortalis-G925 GPU，在 AI 和机器学习网络中的推理速度提升了 20%——AI 和机器学习网络由多个 AI 模型或计算节点组成，用于完成复杂 AI 任务。

在游戏方面，得益于全新的 Arm 光线追踪单元 2 代（RTUv2）——专门负责处理光线追踪计算的硬件模块——Mali G1-Ultra 的光线追踪性能提升 2 倍，能为移动设备带来高端、桌面级的视觉效果。此外，在关键行业基准测试和《暗区突围》（Arena Breakout）、《堡垒之夜》（Fortnite）、《原神》（Genshin Impact）、《崩坏：星穹铁道》（Honkai Star Rail）等游戏应用中，其图形性能提升了 20%。

## Lumex 的可扩展系统核心架构

然而，要支持 AI 优先的体验，移动系统级芯片（SoC）的演进不能仅局限于计算 IP——SoC 是将 CPU、GPU、内存控制器等多个组件集成在单一芯片上的集成电路，也是移动设备的核心——还需覆盖整个互连架构和内存架构。

这正是我们推出全新可扩展系统互连的原因：该互连经过优化，可满足高要求 AI 工作负载及其他计算密集型工作负载对带宽与延迟的需求——带宽指单位时间内数据传输的容量，数值越高，数据传输速度越快；这一优化能确保 Lumex 在实现领先性能的同时，不影响系统响应速度。全新 SI L1 系统互连具备行业最先进且面积效率高的系统级缓存（SLC）——SLC 是位于芯片内部的高速缓存，可临时存储常用数据，减少 CPU 与 GPU 对外部内存的访问，从而提升性能并降低功耗——与标准编译内存（一种内存设计方式）相比，其漏电率降低 71%，能最大限度减少空闲功耗。

对于我们的合作伙伴而言，该系统互连提供了高度灵活、可扩展的解决方案，可针对各类移动设备和消费类设备的不同 PPA 需求进行优化。其中，SI L1 系统互连适用于旗舰移动设备，具备可完全集成的可选 SLC，并支持 Arm 内存标记扩展（MTE）功能以实现一流的安全性——MTE 是一种内存安全技术，可检测缓冲区溢出等内存访问错误；同时，Arm NoC S3 片上网络互连面向对成本敏感且非一致性的移动系统——NoC S3 是基于网络结构的芯片内部互连技术，用于实现芯片内不同组件的高效通信；非一致性指芯片内不同组件对内存的访问方式不统一。

![文章插图](/articles/2025-09-11-arm-lumex-css-3-ai-dd9d5cfd/images/05.webp)

除全新互连外，我们还推出了下一代 Arm MMU L1 系统内存管理单元，该单元可提供安全、经济高效的虚拟化功能——虚拟化技术能在单一硬件上模拟多个独立的运行环境，有效提高硬件利用率——并能扩展应用于各类移动设备和消费类设备。

## 通过物理实现方案，释放行业领先的 PPA 潜力

Lumex 提供可直接用于量产的 CPU 和 GPU 物理实现方案，这些方案针对 3 纳米制程进行了优化，可在多家代工厂使用——代工厂指台积电、三星等专业芯片制造工厂，负责根据芯片设计方案生产芯片——帮助我们的芯片合作伙伴和 OEM 合作伙伴实现以下目标：

::: block-1
- 将这些实现方案作为灵活的构建模块，从而专注于在 CPU 和 GPU 集群层面实现差异化；
- 实现出色的频率与 PPA——频率指 CPU 与 GPU 的运行时钟频率，数值越高，处理速度越快；
- 在向最新的 3 纳米制程节点过渡时，帮助确保首次流片成功——首次流片即芯片设计完成后首次进行生产制造的过程。
:::

## 开发者可立即获取 Lumex 的优势

要充分释放 Lumex 的潜力，开发者需要在实际设备上市前提前获取其功能。因此，我们推出了一系列全新的软件和工具，使开发者现在就能构建原型（快速制作的产品早期版本，用于测试功能）、开发 AI 工作负载，并充分利用 Lumex CSS 平台的全部 AI 功能。这些软件和工具包括：

::: block-1
- 一套完整的支持 Android 16 系统的软件栈，覆盖从可信固件到应用层的全环节——可信固件是设备启动时首先运行的基础软件，能确保系统安全；应用层是直接面向用户的软件层面，比如手机上的各类 APP；
- 一套完整且可免费获取的支持 SME2 技术的 KleidiAI 库——库由预先编写好的代码和函数构成，能简化开发过程；
- 全新的自上而下遥测技术（从应用层到硬件层的性能数据采集和分析技术），可用于分析应用性能、识别瓶颈并优化算法——算法指解决问题的步骤和方法，优化算法能提升程序运行效率。
:::

在成功推出的第一年之后，KleidiAI 现已集成到所有主流 AI 框架中，并已应用于各类应用、设备和系统服务（包括 Android 系统）。这意味着一切已准备就绪：未来几个月内基于 Lumex 的设备上市时，应用程序的 AI 工作负载将立即获得性能和效率的提升。

在图形方面，未来的 Android 版本将支持 RenderDoc（常用的图形调试工具，可帮助开发者查找图形渲染相关的问题）；Lumex 还提供统一的可观测性工具（用于监控和分析系统运行状态的工具），包括 Vulkan 计数器、Streamline 与 Perfetto。其中，Vulkan 计数器用于统计 Vulkan 图形 API 的运行数据——Vulkan 图形 API 是实现应用与 GPU 之间通信的应用程序编程接口；Streamline 是 Arm 推出的性能分析工具；Perfetto 是 Google 推出的系统性能分析工具。开发者可通过这些工具实时分析工作负载、精确调整延迟，并精准平衡设备续航与视觉质量。
