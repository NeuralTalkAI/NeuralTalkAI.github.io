## 正文开始

> OpenAI 团队发布了高度优化的 GPU 内核，适用于带块稀疏权重（block-sparse weights，指将权重矩阵划分为固定大小的块，部分块的权重值全部设为零的权重模式）的神经网络架构，可高效实现线性层（含卷积层）的评估与微分，且权重矩阵的块稀疏模式可灵活配置。

相比 cuBLAS 等现有方案，根据稀疏程度的不同，GPU Kernel 函数的运行速度可**比现有最优方案如 cuBLAS 库快几个数量级。**

## 关键问题

### 问题 1：块大小、稀疏度选择的关键考量及对性能提升的影响

> 本文提出的块稀疏 GPU 内核在实现高效计算时，针对块大小（如 8×8、16×16、32×32）和稀疏度的选择有哪些关键考量，这些参数如何具体影响内核相较于 cuBLAS 等方案的性能提升幅度？

选择块大小（8×8、16×16、32×32）的核心考量是 GPU 硬件特性适配，需平衡内存访问效率与计算并行度：

- 小尺寸块（如 8×8）适合高稀疏度场景，能减少无效数据读取；
- 大尺寸块（如 32×32）在中低稀疏度下更优，可最大化 GPU warp（线程束）的计算利用率。

**稀疏度选择则需匹配任务需求**，:mdnice-bold-italic[核心是在 “减少计算量” 与 “保持模型精度” 间权衡]，实验中常见 50%-90% 稀疏度，既能大幅降低冗余计算，又不会因信息过度丢失影响性能。

:mdnice-bold-italic[性能提升幅度的【关键影响因素】是稀疏模式与硬件的契合度]：

- 该内核针对块稀疏而非随机稀疏优化，能避免传统稀疏计算中 “不规则内存访问” 的瓶颈；
- 当稀疏度在 70%-90% 时，相较于 cuBLAS 的稠密计算，可减少 70%-90% 的算术运算与内存带宽占用，速度提升达 1.5-4 倍，且**稀疏度越高、块大小与 GPU 缓存 / 线程结构越匹配，性能优势越显著。**

### 问题 2：“小世界 LSTM” 解决信息混合问题的核心机制及优势

> 作者构建的 “小世界 LSTM” 通过块稀疏连接实现了网络加宽或加深且保持计算成本稳定，其 “小世界” connectivity（如 Watts-Strogatz、Barabási-Albert 模型）在解决信息混合不充分问题上的核心机制是什么，与传统稠密连接 LSTM 相比有哪些不可替代的优势？

核心机制是**“局部密集连接 + 全局稀疏捷径” 的拓扑结构**：借鉴 Watts-Strogatz 小世界模型，LSTM 的隐藏单元先通过密集块实现局部信息高效交互（保证局部特征提取能力），再通过少量跨块的稀疏连接建立全局信息通路，既避免了稠密连接的高计算成本，又解决了传统稀疏连接中 “信息传递路径过长、混合不充分” 的问题，让不同局部区域的特征能快速融合。

相较于传统稠密 LSTM，其不可替代的优势有两点：

::: block-1
1. **效率 - 性能平衡**：在参数量、计算成本与稠密模型相当的前提下，通过 “加宽 / 加深” 网络提升容量（如隐藏单元数翻倍），且不增加推理时间；
2. **泛化能力更强**：全局稀疏捷径减少了过拟合风险，在长序列任务（如文本生成）中，能更好捕捉长距离依赖关系，实验中亚马逊评论文本生成的比特率（衡量生成质量）比稠密模型更优。
:::

### 问题 3：块稀疏卷积提升 PixelCNN++ 性能的底层逻辑及普适性

> 块稀疏 GPU 内核支持卷积层的块稀疏化，在替换 PixelCNN++ 模型的稠密卷积为块稀疏卷积并保持参数量不变时，通过增加模型深度提升性能的底层逻辑是什么，这种优化方式对其他生成式模型（如图像生成、文本生成）是否具有普适性？

底层逻辑是 **“参数量固定下的计算资源重分配”**：

- 替换稠密卷积为块稀疏卷积后，模型参数量未增加，但计算量大幅减少（减少的计算量可用于 “加深网络层数”）；
- 更深的网络能提取更细粒度、更抽象的特征（如从像素级特征到物体部件特征），且块稀疏结构保留了卷积的局部关联性，避免了 “深度增加导致的梯度消失”，最终在 CIFAR-10 图像生成中，生成样本的清晰度与多样性均优于原稠密模型。

这种优化方式具有**较高普适性**，**【核心前提】是 “生成式模型依赖多层特征提取，且卷积 / 线性层存在大量冗余参数”**：

::: block-1
- 在图像生成（如 GAN、VAE）中，可通过块稀疏卷积加深网络，提升特征表达能力；
- 在文本生成（如 Transformer）中，可将块稀疏应用于注意力层或前馈网络，在保持参数量不变的情况下增加层数或头数，提升长文本建模能力；
- 但需注意，对 “参数冗余度低” 的简单任务（如简单图像分类），该优化的性能提升不明显，更适用于高复杂度、大参量的生成式任务。
:::

## 一、引言

当前深度学习领域[LeCun et al., 2015]的研究在很大程度上受到高效 GPU 核函数可用性的限制——这类核函数用于定义、计算和求导各类模型架构。**目前仅有少数几种线性运算拥有高效的 GPU 实现**，其中包括密集点积（dense dot products，指两个密集矩阵或向量之间的点积运算）、卷积运算（convolutional operations）以及（最新的）深度可分离运算（depth-wise operations，一种将标准卷积拆分为深度卷积和逐点卷积的高效运算方式）。

**【这类】运算以两个变量作为输入**：一个输入通常是网络激活层（对应于当前的小批量数据样本，minibatch 指训练时每次输入模型的部分数据，而非全部数据），另一个输入通常是该层的已学习权重集合。对于密集线性运算，这些权重以密集矩阵或高维密集张量的形式存在。这些权重的两个维度对应于所谓的“特征维度”，其长度分别等于该运算输入层和输出层的“宽度”（即特征数量）。

这类密集线性运算在特征维度上的扩展性较差，因为权重数量与输入特征数量和输出特征数量均成比例。:mdnice-bold-italic[当输入和输出特征数量线性增加时，权重总数会呈二次方增长，计算成本也会随之呈二次方增长——这极大地限制了模型规模的扩大。]

> 理想情况下，我们希望拥有能在两个特征维度上支持“稀疏性”的高效运算。这里的稀疏性（sparsity）指的是：**我们指定一部分权重的值精确为零**。如果某个权重为零，那么与**该权重相关的线性运算就可以直接跳过** （因为任何数值乘以零都等于零），从而减少不必要的计算。因此，稀疏线性运算的计算成本仅与非零权重的数量成比例，而非与总权重数量成比例。

然而，权重具有“任意稀疏模式”的运算存在一个关键问题：它们无法在当前的 GPU 上高效实现。GPU 的核心优势在于其包含数千个可并行工作的计算核心，但这一优势仅适用于具有高度可并行性的运算——而任意稀疏模式的运算由于零权重的分布无规律，难以被拆分为可并行执行的任务，因此无法充分利用 GPU 的并行计算能力。

不过，我们发现：**经过高度优化的“块稀疏运算”** （block-sparse operations，指将权重矩阵划分为固定大小的块，仅对非零块进行计算，零块直接跳过）——**即使块大小最小为 8×8——仍能在当前 GPU 上高效运行。**

![文章插图](/articles/2025-10-01-openai-gemm-gpu-kernel-cublas-348f1023/images/03.webp)

::: image-caption
图 1：随机密集权重矩阵与随机块稀疏权重矩阵的可视化（白色表示权重为零）。我们的新核函数支持在全连接层和卷积层中高效使用块稀疏权重，中间图对此进行了展示。对于卷积层，该核函数允许在输入和输出特征维度上实现稀疏性，但在“空间维度”（spatial dimensions，如图像数据的宽度、高度维度）上的连接仍保持密集。稀疏性在“块级别”定义（右图），块大小至少为 8×8；在块级别上，稀疏模式可完全配置。由于核函数会跳过对零块的计算，因此计算成本仅与非零权重的数量成比例，而与输入/输出特征的总数量无关

## 二、功能特性

> 本次发布的两个主要组件是**块稀疏矩阵乘法核** （block-sparse matrix multiplication kernel）和**块稀疏卷积核** （block-sparse convolution kernel）。这两个核都被封装成了 TensorFlow[Abadi et al., 2016]操作符（ops），以便于使用，且这些核可轻松集成到其他框架中，例如 PyTorch。

**这两个核均支持任意块大小，并针对 8×8、16×16 和 32×32 的块大小进行了优化**。其中，

- 矩阵乘法核支持通过掩码矩阵（masking matrix）指定的任意块布局，此外，特征轴（feature axis）也可配置。
- 卷积核支持通过配置格式（详见 API 文档）指定的、非连续的输入/输出特征块（无论块大小是均匀还是非均匀），不过 32×32 的整数倍块大小性能最佳。除了支持膨胀（dilation）、步幅（striding）、填充（padding）和边缘偏置（edge biasing）外，该卷积核还支持任意大小的密集空间滤波器（dense spatial filter）。

**本次发布还包含了多种高效的辅助操作符** （helper ops），可用于执行常见流程，例如激活值的层归一化（**layer normalization**）与批量归一化（**batch normalization**）、权重的 L2 归一化（**L2 normalization**）、丢弃层（dropout）、激活函数（**activation functions**）以及按元素运算（**elementwise math**）。

> 由于稀疏网络支持的激活张量比密集网络大得多，因此在 GPU 硬件上，**这些操作往往受带宽限制，而非计算限制**。低精度格式能显著降低带宽，从而帮助缓解这一问题。

为此，这些核除了支持 fp32 外，还支持 fp16 ；同时，bfloat16（脑浮点格式，一种更紧凑的浮点格式）等其他紧凑格式也在开发中。

## 三、基准测试

### 3.1 与 cuBLAS 和 cuSPARSE 核的性能对比（以 GFLOPS 为指标）

为验证本文所提核的效率，我们针对块稀疏权重线性层，将其与三种基准技术进行了对比。所有测试均在 NVIDIA Pascal Titan X GPU 上进行，批大小（minibatch size）设为 32，块大小设为 32×32。

**第一种基准技术是将 cuBLAS 核直接用于稀疏权重矩阵** （即“朴素用法”）。由于该技术不会“跳过”值为 0 的权重块，因此其计算复杂度与矩阵的总元素数量成正比，而非与非零块的数量成正比——这导致该技术会执行大量不必要的运算。

![文章插图](/articles/2025-10-01-openai-gemm-gpu-kernel-cublas-348f1023/images/05.webp)

::: image-caption
图 3：在权重矩阵大小为 12288×12288、批大小为 32、块大小为 32 的条件下，块稀疏矩阵乘法相对于 cuBLAS（CUDA 8）矩阵乘法的实测速度提升（以相对 GFLOPS 为指标）。其他基准技术的性能通常比 cuBLAS 更差。图中纵轴为“相对于 cuBLAS 的速度提升因子”，数值范围 0-30；横轴为“稀疏度（%）”，数值范围 0-100，曲线显示稀疏度越高，速度提升因子越大，最高接近 30

本文所提核相对于该技术的速度提升情况如图 3 所示。可以看到，**随着稀疏度的提高，速度提升因子（speed-up factor）会接近$\frac{1}{1-s / 100}$（其中 s 为稀疏度百分比），这与预期一致。**

我们还将本文所提核与另外两种基准技术进行了对比：

1. 通过 cuBLAS 执行一系列小块矩阵乘法来实现块稀疏矩阵乘法；
2. 使用 cuSPARSE 库（NVIDIA 推出的稀疏矩阵计算库）实现块稀疏矩阵乘法。

与第一种基准技术不同，**这两种方法的计算复杂度均仅与非零块的数量成正比**。但在:mdnice-bold-italic[实验中，这些基准技术的性能仍比上述“cuBLAS 朴素用法”更差] ——无论稀疏度如何，其 GFLOPS（每秒十亿次浮点运算）数值均不超过 50。

> :mdnice-bold-italic[而本文所提的的 GPU 内核，在性能 GFLOPS 上比这些基准技术快一到两个数量级。]

## 四、实验

我们的新 kernel 为学习算法和神经网络架构开辟了广阔的新可能。在本节，将基于具有固定稀疏拓扑结构的相对简单的块稀疏模式进行实验。需要说明的是，**从原理上讲，这些 kernel 支持更为新颖的方法（例如学习稀疏结构）和更复杂的模型；相关探索将留待未来工作开展。**

### 4.1 具有深度更新的 LSTM

> 块稀疏核使我们能够高效实现具有块稀疏连接的 LSTM。这里的“稀疏连接”指的是：**将 LSTM 中的线性操作替换为块稀疏线性操作**。:mdnice-bold-italic[通过稀疏连接，我们能够在不增加参数数量的前提下拓宽网络（即增加隐藏层单元数量）。]

全连接循环连接的 LSTM 具有一个理想特性：在时间步$t$时，每个激活值（神经元输出）都是时间步$(t-1)$时所有隐藏层激活值和所有输入的函数。总得来说有三点：

::: block-1
1. **全连接循环 LSTM 的核心优势：信息完全混合**。全连接意味着 LSTM 在时间步t计算神经元激活值时，会用到前一时间步(t-1)的所有隐藏层激活值（每个神经元都与前一步所有神经元连接）和全部输入信息。这种 “无遗漏” 的连接模式，能让不同来源、不同神经元的信息在时间步间充分融合，避免信息孤立，是其 “理想特性” 的核心。
2. **简单块稀疏 LSTM 的关键问题：信息混合不充分**。块稀疏连接会将 LSTM 的权重矩阵拆分为固定大小的块，仅保留部分非零块、跳过零块计算（以减少冗余运算）。但这种设计导致 “并非所有神经元都有直接连接”—— 比如 A 块的神经元可能无法直接接收 B 块神经元的信息，只能通过间接路径传递，甚至部分信息因连接缺失无法传递，最终造成时间步间的信息无法像全连接那样 “完全混合”。
3. **研究背景：已有解决方案的方向**。文中提及的 [Wen et al., 2017] 也发现了 “稀疏连接导致信息混合不足” 的问题，因此**提出 “结构化稀疏方法”—— 本质是通过设计更规整、更合理的稀疏连接模式** （而非简单随机的块稀疏），:mdnice-bold-italic[在保留稀疏性（降计算成本）的同时，尽量弥补信息混合能力的损失，为后续优化（如文中后续提到的 “小世界 LSTM”）提供了思路参考。]
:::

### 4.2 小世界网络

> 在选择稀疏连接方式时，我们:mdnice-bold-italic[从“小世界网络”（一种具有高聚类系数和短平均路径长度的网络结构，类似现实中的社交网络）领域汲取了灵感]，具体说明如下。根据[Watts, 1999]的定义，**若一个网络满足以下两个特性，则可被称为小世界网络：**

1. **聚类系数较高**。聚类系数是衡量网络连接局部性的指标，当网络中存在大量“团”或“近团”结构（即几乎完全互连的子网络）时，聚类系数会较高。需要注意的是，采用块稀疏连接构建的 RNN（循环神经网络）天然具备这一特性。
2. **节点（神经元）间的平均路径长度$L$与节点（神经元）总数$N$呈对数关系**，即$L \propto \log N$。其中，节点间的路径长度指两节点间最短路径的步数。较短的平均路径长度能够实现信息的快速混合。

**小世界网络的一个著名例子是人类社交网络** [Watts, 2004]：

- 我们的亲友和熟人之间往往也互相认识（:mdnice-bold-italic[高聚类性]），而从地球上任意一个人到另一个人，平均只需“六步”（:mdnice-bold-italic[短平均路径长度]）。
- 另一个例子是**人类大脑，其解剖学和功能网络通常也表现出小世界特性** [Bassett and Bullmore, 2006]。

以下是几种生成具有小世界特性网络的算法：

::: block-1
1. 随机块稀疏连接。需注意，具有非 trivial 大小块（即块大小不可忽略）的简单块稀疏结构本身就具有一定的聚类性，由此可构建最简单的小世界 RNN。
2. 瓦茨-斯托加茨（WS）模型[Watts and Strogatz, 1998]。构建 WS 网络的算法步骤如下：首先构建一个$K$维环状格点网络，该网络具有密集的纯局部连接（即每个节点仅与格点内特定距离范围内的其他节点连接）；随后，将所有连接中的一部分（占比$k\%$）替换为随机连接，其余$(100-k)\%$的局部连接则保留。
3. 巴拉巴西-阿尔伯特（BA）模型[Barabási and Albert, 1999]。构建该类网络的算法步骤如下：首先初始化一个包含$m_0$个节点的全连接网络；之后，每次新增一个节点，并使该新节点与$m \leq m_0$个已有节点连接——新节点与某个已有节点连接的概率，与该已有节点的连接度（即连接数量）成正比。这一机制会导致网络呈现幂律度分布，即极少数节点拥有极高的连接度（“富者愈富”现象）。
:::

**我们的块稀疏 GPU 核支持在块级别实现具有 WS 和 BA 连接特性的模型**。不同连接类型的示意图可参见图 6。

![文章插图](/articles/2025-10-01-openai-gemm-gpu-kernel-cublas-348f1023/images/10.webp)

::: image-caption

> “小世界连接特性神经网络”具有两大核心优势，本质是通过优化网络拓扑结构，平衡“网络规模扩展”与“信息传递效率”。

#### 优势1. 解决“宽网络参数爆炸”问题

传统神经网络若要“加宽”（增加隐藏层单元数），权重参数会随输入/输出特征数呈**二次增长** （如密集矩阵乘法中，单元数翻倍则参数数翻四倍），导致计算和内存成本剧增。

而小世界连接**通过“块稀疏拓扑”（局部密集连接+全局少量稀疏捷径），仅保留关键非零连接块**，参数数量仅与非零块规模相关，而非总单元数，因此能在参数成本可控的前提下，大幅增加隐藏层单元数，实现“宽网络”训练。

#### 优势2. 保证“大网络信息快速混合”

网络加宽后易出现“信息传递延迟”（如传统稀疏网络中，神经元间路径过长，信息需多步才能传递）。

但小世界网络的【核心特性】是“**平均路径长度与神经元总数呈对数关系”** ——即单元数即便大幅增加（如从1千增至10万），任意两神经元间的最短路径仅需少量步骤（如从3步增至5步）。

这使得即便RNN状态规模极大，信息也能在极少时间步内跨单元传递、充分混合，避免因网络过宽导致的信息割裂问题。

### 4.3 小世界 LSTM

我们训练了具有深度更新和小世界块稀疏连接特性的 LSTM，并将其称为“小世界 LSTM”。在一项大规模实验中，我们遵循[Radford et al., 2017]的实验设置，在亚马逊评论语料库[McAuley et al., 2015]上训练字节级生成模型（以字节为基本单位生成文本的模型）。

- 得益于更高效的实现，模型训练轮次从 1 轮增加到 4 轮；
- 同时，批量大小也提升了 4 倍，从而保证总更新次数不变。
- 与其他实验一致，我们训练了参数数量近乎相等且超参数（模型训练前手动设置的参数，如学习率、批量大小等）完全相同的模型，**以对比密集权重矩阵与块稀疏权重矩阵的性能差异。**

其中，密集模型的状态大小为 3168；稀疏模型采用 BA 连接模式，有效稀疏度约为 97%，状态大小为 18432。

密集模型的性能达到每字节 1.058 比特（bits per byte，衡量文本生成模型性能的指标，:mdnice-bold-italic[数值越低表示生成文本质量越好]），这一结果已显著优于此前在该数据集上报道的 1.12 比特/字节；**而稀疏模型的性能进一步提升，达到 1.048 比特/字节。**

### 4.5 块稀疏卷积网络

> 最后，我们测试了将密集（常规）卷积核替换为块稀疏卷积核，是否能在生成建模基准测试中提升性能。为确保对比的公平性，我们采用了现有最优（SOTA）模型的公开实现代码，在保持所有超参数（包括优化相关超参数）不变的前提下，对模型进行稀疏化和加深处理，以保证总参数数量大致不变。

具体而言，我们采用了 PixelCNN++[Salimans et al., 2017]生成模型的公开实现代码，并**将其中的常规卷积替换为具有块对角结构的块稀疏卷积——这种结构也被称为分组卷积** [Zhang et al., 2017, Xie et al., 2016]（将输入特征图分成多个组，每组单独进行卷积运算，以减少计算量）。与[Zhang et al., 2017]类似，我们在每个块稀疏卷积后加入了 Shuffle 操作（洗牌，打乱特征图的分组顺序，促进不同组间的信息交流）。在我们的实现中，洗牌操作无需额外的计算或内存开销，因为它可以与卷积操作合并——只需对稀疏结构进行洗牌即可。

实验结果表明，**在保持总参数数量大致不变的前提下，将模型各阶段的深度提升 2 倍或 4 倍** （同时提高稀疏度），能够显著提升模型在“每维度比特数（bpd，衡量图像生成模型性能的指标，数值越低表示生成图像质量越好）”指标上的表现。当深度提升 4 倍时，模型的 bpd 达到 2.90——据我们所知，这是目前文献中报道的最优结果。

> 这些结果与[Zhang et al., 2017]和[Xie et al., 2016]的发现一致：他们发现类似的分组卷积能够降低有监督任务（如图像分类）的错误率。**关于块稀疏卷积可显著提升性能的更多实验证据，读者可参考上述两篇文献。**

## 五、相关工作

> 文献中有大量证据表明，:mdnice-bold-italic[采用块稀疏线性操作的架构能够显著提升模型性能。]

例如，在[Xie et al., 2016]中，研究者提出了一种名为 ResNeXt 的新型卷积网络架构，该架构采用**块稀疏卷积**，实现了对当时最优结果（SOTA）的超越。随后，ShuffleNet[Zhang et al., 2017]也采用了块稀疏卷积，并且与我们的卷积实验类似，结合了 Channel Shuffle（洗牌）操作。**这类架构有望从高效的块稀疏 GPU 核中显著获益。**

深度可分离卷积[Simonyan and Zisserman, 2014]可被视为块大小为 1 的块稀疏卷积——它将标准卷积拆分为“深度卷积”（对每个输入通道单独卷积）和“逐点卷积”（将深度卷积的输出融合为新的特征图），能大幅减少计算量和参数数量。自[Simonyan and Zisserman, 2014]首次提出以来，深度可分离卷积已在多篇文献中被用于推动图像分类领域的最优结果（SOTA）发展，例如后续的 Xception[Chollet, 2016]和 MobileNet[Howard et al., 2017]架构。

> 我们在 RNN 中引入块稀疏性的动机之一——“在不显著增加计算量或参数数量的情况下实现更大的状态大小”——已被其他多种方法成功解决。

- [Sak et al., 2014]提出的投影 LSTM（Projection LSTM），通过减少 LSTM 中“隐藏层到隐藏层”转换过程的参数数量和计算量，实现了对高维状态的高效利用；
- 该方法随后被扩展应用于大规模语言建模任务，并取得了最优结果[Jozefowicz et al., 2016]。[Kuchaiev and Ginsburg, 2017]进一步拓展了这项工作，探索了更多适用于 LSTM 的因子分解方法（通过矩阵分解减少参数数量）。

与我们的小世界 LSTM（采用固定块级别稀疏模式训练）不同，**已有研究探索了在 RNN 中学习结构化稀疏性的更灵活方法**。

- 分组 L1 正则化[Yuan and Lin, 2006]是一种常用技术：通过合理定义参数组，鼓励组内参数整体为零，从而实现结构化稀疏。
- **与我们的工作密切相关的是**，[Narang et al., 2017]通过对权重矩阵块进行精心调度的阈值处理（将小于阈值的参数置零）和分组 L1 正则，实现了块稀疏 RNN 的学习。
- [Wen et al., 2017]则通过对“内在稀疏结构权重组”（对应 LSTM 权重矩阵中特定单元的行和列）施加分组 L1 正则，实现了单元级剪枝（移除神经网络中冗余的单元，减少模型复杂度）。

在循环神经网络中引入内部步骤的做法并非由我们首次提出。例如，在[Zilly et al., 2016]和[Graves, 2016]中，研究者训练的 RNN 在每个“外部时间步”（对应原始序列的一个时间单位，如文本中的一个词）内包含多个“内部步骤”（模型内部额外的计算步骤，用于增强信息处理能力）。

## 六、研究方向

> 块稀疏内核仍**存在大量【未】被探索的研究方向与潜在应用场景**。下文列出了一些开放性问题及未来研究建议：

当前已有多项研究（如[Cheng et al., 2017]中总结的各类近期工作）表明，神经网络训练完成后，其权重中很大一部分可被剪枝（指移除冗余的零值或接近零值的权重，以降低模型复杂度）。但**以往这些剪枝结果往往无法转化为实际运行时间（wall-clock time）的提速，核心原因在于缺乏能够利用稀疏性的 GPU 内核**。那么，当:mdnice-bold-italic[结合权重的块级剪枝（block-wise pruning，即按块为单位移除零值权重）与块稀疏内核时，推理阶段能实现多大程度的实际运行时间提速？]

在生物大脑中，网络的稀疏结构（除了连接强度外）部分是在发育过程中确定的。那么在人工神经网络中，:mdnice-bold-italic[我们能否实现类似机制——利用梯度不仅学习连接权重的大小，还学习最优的稀疏结构（即哪些位置需要保留连接、哪些位置可设为零）？] 近期已有研究提出了块稀疏循环神经网络的学习方法[19]（Narang et al., 2017），此外我们团队近期也提出了一种用于神经网络 L0 正则化的算法[21]（Louizos et al., 2017），这些成果或可为此方向提供技术支撑。

我们已成功训练出包含数万个隐藏单元的 LSTM 模型，且该模型在文本建模任务中表现更优。更普遍地说，:mdnice-bold-italic[稀疏层使得训练“具有超大权重矩阵但参数数量和计算成本与小型密集模型相当”的模型成为可能。那么，在哪些应用领域中，这类模型对性能的提升效果最为显著？]

## 七、结论

> 我们发布了高度优化的 GPU 内核，适用于具有块稀疏权重的神经网络的基于梯度的学习与推理。在基准测试实验中，我们发现所提出的 GPU 内核确实比未针对块稀疏权重优化的其他内核效率更高。

我们利用这些内核实现了小世界 LSTM（small-world LSTMs，具有小世界网络特性的 LSTM 模型，小世界网络需满足“聚类系数高”和“节点间平均路径短”两个条件），**该模型能够扩展到比传统 LSTM 大得多的状态规模** （state size，指 LSTM 隐藏层的维度，维度越大理论上能捕捉的信息越丰富）。我们对比了密集网络[Radford et al., 2017]与更宽的稀疏网络（两者均在亚马逊评论数据集[McAuley et al., 2015]上通过生成式学习获得特征表示），得出：

- 在情感分类任务中的有效性，发现稀疏网络的宽状态确实有助于情感识别，在多个情感分类基准测试中均达到了当前最佳性能（state-of-the-art）。
- 在亚马逊评论数据集上，该稀疏模型的每字符比特数（bits-per-character，衡量文本生成质量的指标，数值越低表示生成文本越接近真实数据分布）结果也是目前文献中报道的最优值；
- 在 CIFAR-10 图像生成任务中，使用稀疏层的模型在每维度比特数（bits-per-dimension，衡量图像生成质量的指标，数值越低表示生成图像质量越高）性能上同样有所提升。

块稀疏神经网络领域仍有大量内容有待探索，前面已列出部分潜在的富有价值的未来研究方向。
