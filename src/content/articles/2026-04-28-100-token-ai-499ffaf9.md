## 这是一场什么活动？

> 这个计划的全称有点长，但关键词非常诱人：**完全免费、定向发放、面向创造者**。

它不是抽奖，也不是噱头大于实质的“体验金”。根据活动页面信息，小米这次拿出了整整 100,000,000,000,000 个 Token 的权益池，计划在一个月内分批发放给通过评估的申请者。截至 4 月 28 日晚间，该页面显示的剩余 Token 数量约为 91.7 万亿。也就是说，活动刚开始不到一天，已经有超过 8 万亿 Token 被“抢”走，而这个数字还在以肉眼可见的速度跳动。

## 谁有资格“薅羊毛”？怎么薅？

> 虽然门槛很低，但小米这次设置了一个“温柔”的筛选机制：**提交表单，等待评估。**

申请流程不复杂：进入活动页面，点击“立即申请”，填一份表单，描述一下你正在做的项目、使用的 AI 工具、底层模型，再附上一些证明材料即可。提交之后，大约 3 个工作日，评估通过的用户就会收到一封确认邮件。接下来，只要用表单里填写的那个邮箱登录或注册 Xiaomi MiMo API 开放平台，权益会在 24 小时内自动到账。

这里有几个细节需要特别注意，官方在常见问题里反复强调了：

- 如果你已经有开放平台账号，**务必确保该账号绑定的邮箱与你表单中填写的一致**。如果账号是用手机号注册的，需要提前绑定那个邮箱。
- 如果还没有账号，收到通过邮件后，直接用它提示的方式，用那个邮箱注册就好。
- 权益发放后，**是有有效期的**，过期未使用会自动失效，所以拿到之后千万别把它晾在那里吃灰。

至于最终能拿到多少 Token、是哪种类型的权益，则完全取决于你表单内容的质量。官方给出的标准很明确：**填写越详细、项目越具体，评估通过率越高，权益档位也可能越高**。这很公平——真正的创造者，总能在一份表单里展现出自己折腾的事情有多酷。

## 发的到底是什么？能用来干什么？

> 发放的权益主要分两种形式：**Token Plan（订阅制套餐）和赠金**。

Token Plan 可以直接配置到 Claude Code、Cursor、OpenClaw 等主流编程工具中使用，相当于给你配好了一个可以即插即用的“模型供应站”。而赠金则会充入开放平台的账户余额，用于按量计费的 API 调用。无论哪一种，都可以调用 MiMo 系列模型。

说到模型，这次激励计划背后的“主角”，正是刚刚公测并开源的**Xiaomi MiMo-V2.5 系列**。这批模型有一个很鲜明的特点：不仅能力顶，而且完全采用 MIT 协议开源，支持商用推理部署与二次训练，不需要额外授权。对于想深度定制模型的开发者来说，这是一个相当友好的信号。

> V2.5 系列包含两款模型：

- **MiMo-V2.5-Pro**，专攻复杂任务，深度适配 Agent 与 Coding 应用。在 GDPVal-AA 和 ClawEval 这类硬核评测榜单上，它直接冲到了全球开源模型的第一名。
- **MiMo-V2.5**，则是一个原生全模态模型，支持文本、图像、视频和音频理解，同时具备强大的 Agent 能力。

## 没收到通知怎么办？

活动页面还贴心地解答了几个“实操翻车”现场。比如，如果提交后迟迟没收到邮件，第一步先检查垃圾邮件箱，再确认一下填写的邮箱地址是否正确。

- 如果 3 个工作日过去依然石沉大海，可以试着重新提交一次申请。
- 还是不行的话，就直接通过开放平台的“联系我们”渠道反馈。

小米把这条路留得挺宽，显然不希望任何一个合格的申请者因为技术细节被卡出去。
