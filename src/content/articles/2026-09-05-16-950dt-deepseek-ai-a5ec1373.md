> 9 月 4 日，彭博社援引知情人士消息爆出重磅信息[1]：中国 AI 大模型企业 DeepSeek 计划在内蒙古乌兰察布的吉瓦级数据中心内部署**至少 16 万颗华为昇腾 950DT AI 加速芯片，若顺利落地将成为全球已知规模最大的华为昇腾芯片集群之一。**

与市场普遍认知不同，这批定位为“训练推理双能”的高端芯片，**将全部用于模型推理而非训练**，:mdnice-bold-italic[DeepSeek 的训练环节仍将依赖英伟达 GPU]。受高端存储元器件短缺与多客户需求分配影响，**华为今年 950DT 产能仅数十万颗，该订单完整交付周期将超过一年。**

## 一、16 万颗昇腾 950DT：DeepSeek 的国产算力豪赌

### 1.1 彭博独家爆料：吉瓦级数据中心的核心配置

> 本次 16 万颗昇腾 950DT 的采购计划，隶属于 DeepSeek 在内蒙古乌兰察布建设的 1 吉瓦级超大型 AI 数据中心项目，该项目也是 DeepSeek 算力基础设施建设的核心工程。

按照规划，16 万颗昇腾 950DT 仅占该数据中心总算力的一部分，项目整体采用“自建+外部租赁”并行的模式推进，预计 2027 年底至 2028 年初实现部分算力上线运营。项目全部建成后，将成为中国企业运营的规模最大的 AI 数据中心之一。

:mdnice-bold-italic[DeepSeek 与华为的合作不止于硬件采购，双方还联合定义昇腾超节点架构，针对长文本推理场景优化时延、提升吞吐并控制成本，同时兼顾集群向万卡级规模扩展的需求。]

### 1.2 反直觉选择：只做推理，不做训练

> 一个值得关注的细节是：尽管华为昇腾 950DT 的产品定位覆盖训练与推理全场景，但 DeepSeek 明确表示这批芯片暂不用于模型训练，仅承载推理业务。

推理是 AI 模型面向用户服务的“最后一公里”，用户每次调用 API、发送对话请求，背后都由推理算力支撑。将推理环节全面切换到国产芯片，**意味着 DeepSeek 的用户端服务将率先摆脱对英伟达硬件的依赖。**

::: block-1
:mdnice-bold-italic[而训练环节之所以仍保留英伟达方案，核心原因在于大模型训练对软件生态、算子适配、集群通信的要求远高于推理]，国产算力生态在训练场景的成熟度仍有提升空间。
:::

## 二、昇腾 950DT：撑起 16 万卡集群的硬件底座

### 2.1 芯片核心规格与性能定位

> 昇腾 950DT 是华为昇腾 950 系列的高端型号，基于第三代达芬奇架构打造，专为大模型全生命周期设计，覆盖预训练、后训练及推理全流程，尤其适配生成式大模型的长文本解码场景。

核心规格方面：

- 该芯片搭载自研 HiZQ 2.0 HBM 内存，容量达 144GB，内存访问带宽 4TB/s；
- 芯片间互联带宽达 2TB/s，相比前代提升 2.5 倍；
- 算力层面，FP8 精度算力达 1 PFLOPS，FP4 精度算力达 2 PFLOPS，原生支持 FP8、MXFP8 等多种低精度数据格式。

![文章插图](/articles/2026-09-05-16-950dt-deepseek-ai-a5ec1373/images/03.webp)

::: image-caption
昇腾950PR与昇腾950DT两款AI芯片规格对比，从AI子系统、内存、SOC三大维度罗列参数。AI子系统部分对比Cube Core、Vector Core数量，涵盖MXFP4、INT8、BF16等多精度下Cube、Vector以及两者合计的算力指标；内存板块展示两款芯片不同版本的内存容量与带宽；SOC模块包含Linx816 CPU子系统，以及DVPP图像预处理、编解码单元的核心数量、处理帧率、分辨率上限。整体可见昇腾950DT在核心数量、算力、内存带宽多数指标上优于昇腾950PR。
:::

![文章插图](/articles/2026-09-05-16-950dt-deepseek-ai-a5ec1373/images/04.webp)

::: image-caption
昇腾 950 芯片架构示意图，该图直观展示了昇腾 950 的 Chiplet 多 Die 合封架构，整芯片集成 2 个 AI Die、2 个 IO Die 与多组高速片上内存，通过 D2D Clink 与内存接口互联，构成 UMA 统一内存访问整体。AI Die 集成第三代 DaVinci Core 与 AI CPU 子系统，负责核心 AI 计算与通用逻辑处理；IO Die 承载灵衢总线接口、PCIe 5.0 控制器与 CCU 集合通信单元，承担芯片内外的数据交互。计算与 IO 分离的 Chiplet 设计，既通过复用计算 Die 降低了研发成本，又能灵活配置显存规格，快速衍生出 PR 与 DT 两款产品，差异化适配推理与训练场景，提升了架构的市场覆盖能力。
:::

![文章插图](/articles/2026-09-05-16-950dt-deepseek-ai-a5ec1373/images/05.webp)

::: image-caption
AI Core 架构及各层级 SRAM 示意图。这张图拆解了单个 AI Core 的计算与存储层级，核心由 Cube Core 张量单元与 Vector Core 向量单元组成，二者搭配独立的 L0、L1 缓冲区与 Unified Buffer 统一缓存。各级 SRAM 按计算单元的访问特性定制容量与位宽：Cube Core 的 L0C Buffer 专为矩阵运算做 Tiling 优化，Vector Core 的 Unified Buffer 适配向量计算的不规则访存。多级 SRAM 将大部分数据访问限制在核内，极大降低了共享 L2 Cache 的带宽压力；Cube 与 Vector 之间的专用数据通路，支持 CV 融合算子的高效数据交互，避免了跨核数据搬运的额外开销，是融合算子性能提升的硬件基础。
:::

在超节点架构下，单柜可部署 64 颗昇腾 950DT 芯片，1024 卡集群的 FP8 总算力可达 1 EFLOPS，可支撑千亿参数大模型的高效推理与训练任务。

![文章插图](/articles/2026-09-05-16-950dt-deepseek-ai-a5ec1373/images/06.webp)

::: image-caption
昇腾 950 访问 CPU 超大内存池示意图，其通过 UB 总线直接访问 CPU 侧超大内存池的能力，无需经过 PCIe 协议转换与 CPU 拷贝，实现高带宽、低延迟的内存扩展。对于大模型推理中的超长上下文 KV Cache、推荐系统等大内存需求场景，可将不常访问的数据存放在 CPU 内存池中，按需高速读取，突破了 NPU 片上内存的容量限制。
:::

### 2.2 产能瓶颈：交付周期超一年的现实约束

> 大规模采购的核心制约来自产能。受高端存储等核心元器件短缺影响，:mdnice-bold-italic[华为今年昇腾 950DT 的产量被限制在数十万颗级别，同时华为还需要平衡其他行业客户的订单需求，并保留少量出口配额。]

在此背景下，DeepSeek 的 16 万颗订单完整交付周期预计将超过一年。知情人士同时透露，**DeepSeek 的采购意愿高于当前华为产能上限，后续仍有进一步加量的可能。**

产能爬坡速度将直接决定国产算力替代的节奏。目前昇腾 950DT 已提前于 2026 年 Q3 开启小批量交付，相比原计划的 Q4 发布提前了近 4 个月，字节、阿里、腾讯等头部互联网企业均已启动测试适配。

## 三、从单点突破到行业共识：国产算力替代加速

### 3.1 第二家头部企业跟进：范式智能超 10 亿采购

> DeepSeek 的大规模算力布局并非孤例。就在同一时期，港股 AI 企业范式智能（原第四范式）也与华为达成大规模算力合作，

范式智能拟**出资超过 10 亿元采购华为昇腾 950 芯片，用于支撑金融、制造等领域的 AI 模型落地。**

双方核心管理层已完成战略会晤，:mdnice-bold-italic[新增算力将主要用于范式智能在手订单项目交付与 AI 产品研发。2026 年上半年，范式智能 API 业务收入同比增长 860.8%，Token 调用量同比增长约 620%，在手订单总额约 70 亿元，算力扩张需求迫切。]

此前范式智能已公告斥资 4 亿元采购 GPU 服务器，此次与华为的合作是其在国产算力生态的持续加码，也标志着国产算力替代从“单点突破”走向“行业共建”。

### 3.2 智谱“牛来”大模型：国产算力支撑的高性价比前沿方案

> 2026 年 8 月智谱正式发布并开源GLM-5.3-Flash（代号“牛来”），这是 GLM-5 系列首款原生多模态模型，总参数量 320B、单 Token 激活参数 18B。

:mdnice-bold-italic[该模型综合能力比肩 Claude Opus 4.8，但 API 定价仅为后者约 1/40，其全球线上服务全部由超 10 万张国产芯片组成的集群承载。]

通过自研推理引擎、EPD 分离架构与稀疏-线性混合注意力架构的协同优化，模型端到端性能提升 3 倍，在大幅压缩推理成本的同时迈入全球前沿模型能力区间。

## 四、深层观察：国产算力的破局与边界

### 4.1 训练 vs 推理：替代的分步路径

> 从 DeepSeek 和范式智能的选择可以清晰看出国产算力替代的分步路径：先易后难，先推理后训练。

推理场景对软件生态的依赖相对较低，业务模式标准化程度高，通过工程优化更容易发挥硬件性能，是国产芯片规模化落地的最佳切入点。而训练场景涉及算子库、编译器、分布式训练框架等完整生态，需要更长时间的打磨与适配。

这种分步替代的策略，既可以快速降低对进口芯片的依赖，又能为生态完善争取时间，是当前阶段务实且高效的选择。

:::

### 4.2 产能与生态：真正的考验还在后面

> 16 万颗芯片的订单，是对国产算力的一次大规模压力测试。**真正的考验在于能不能稳定交付、能不能规模化运行、能不能把成本降到比进口方案更有竞争力的水平。**

当前华为昇腾的生态已经跨过“能用”的门槛，进入**“比性能、比成本、比稳定性”的新阶段**。接下来:mdnice-bold-italic[产能爬坡速度、软件生态迭代速度、行业客户的接受度]，将共同决定国产算力替代的最终天花板。

::: block-1
可以确定的是，:mdnice-highlight[随着头部企业纷纷下场验证与采购，国产算力已经从备选方案变成了主流选项之一]，中国 AI 基础设施的自主可控进程正在加速。
:::
